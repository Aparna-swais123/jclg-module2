# Student Welfare Dashboard

This frontend now uses Next.js with the App Router.

## Run locally

1. Install dependencies: `npm install`
2. Optionally copy `.env.example` to `.env.local` and set the FastAPI URL.
3. Start the frontend: `npm run dev`

The app is served at http://localhost:3000 by default. The FastAPI backend remains in `../Backend` and defaults to http://127.0.0.1:8000.
